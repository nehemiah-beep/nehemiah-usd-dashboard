## 🪙 What is Tempo Forge?

Tempo Forge is a community-built dashboard that lets anyone deploy, mint, and manage TIP-20 stablecoins on the Tempo testnet — no coding required.

Built on top of Tempo's official SDK, it provides a clean, modern UI for the full stablecoin lifecycle.

---

## ✨ Features

- 🔑 Wallet Connect — Connect with MetaMask or create a Passkey account
- 🪙 Deploy Stablecoin — Launch your own TIP-20 USD-pegged token in seconds
- ✦ Mint Tokens — Mint tokens to any address with optional memo
- 🔥 Burn Tokens — Reduce supply by burning tokens
- 📊 Supply Cap — Set a hard cap on total token supply
- 🛡 Transfer Policy — Blacklist or whitelist specific addresses
- ⏸ Pause/Unpause — Freeze transfers in case of emergency
- 🔑 Role Management — Grant and revoke issuer roles
- 🌊 Fee AMM — Add and remove liquidity from Tempo's DEX
- 🎁 Rewards — Distribute and claim token rewards

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- pnpm

### Installation

git clone https://github.com/nehemiah-beep/nehemiah-usd-dashboard.git
cd nehemiah-usd-dashboard
pnpm install
cp .env.example .env
pnpm dev

Open http://localhost:5173 in your browser.
